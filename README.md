# 🚢 Морской бой (Battleship)

Браузерная версия классической игры «Морской бой» с удобным интерактивным управлением и расстановкой флота с помощью мыши.

## ✨ Особенности игры
* **Интерактивная расстановка (Drag-and-Drop):** перетаскивайте корабли прямо из дока на игровое поле.
* **Быстрая авторасстановка:** кнопка «Случайно» мгновенно расставит весь флот за вас.
* **Гибкое управление кораблями:** удобный поворот и возврат кораблей в док в один клик.
* **Очистка поля:** сброс расстановки одной кнопкой «Очистить».

## 🎮 Управление при расстановке флота
* **Перетаскивание (зажать ЛКМ):** переместить корабль из дока на поле или поменять его позицию.
* **Клик левой кнопкой мыши (ЛКМ) по кораблю на поле:** повернуть корабль против часовой стрелки.
* **Клик правой кнопкой мыши (ПКМ) по кораблю на поле:** повернуть корабль по часовой стрелке.
* **Двойной клик по кораблю:** убрать корабль обратно в док.

## 🛠 Технологии
* **HTML5** — структура игровых полей и интерфейса.
* **CSS3** — визуальное оформление флота и сетки.
* **JavaScript** — игровая логика, механика перетаскивания и бой.

## 🚀 Как запустить
1. Скачайте файлы репозитория на компьютер (или клонируйте репозиторий).
2. Откройте главный HTML-файл (например, `index.html`) в любом современном браузере.
3. Расставьте корабли и нажмите кнопку **«В бой!»**.
